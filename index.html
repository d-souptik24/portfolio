ECG Digitalization System

An end-to-end system that photographs paper ECG printouts, reconstructs the original 12-lead time-series signal using a deep learning ensemble, and displays clinical-grade plots on a Flutter app. Designed to digitize legacy hospital archives in resource-limited clinics.

  • 3-stage deep learning pipeline: homography normalization (Stage0Net), grid-warp rectification (Stage1Net), EfficientNet ensemble digitization with TTA (Stage2)
  • ESP-32 CAM module for autonomous image capture with OLED status display and 3-retry upload logic
  • Flask backend with async processing (~5–8 min on CPU), status polling, and server-rendered Matplotlib clinical plots
  • Flutter app with Riverpod state management, hybrid local + server record history, and GoRouter navigation
Repository

Arduino Temperature Monitoring Prototype

A working prototype that reads ambient temperature through an NTC thermistor and converts the analog signal to accurate Celsius values using the Steinhart–Hart equation. Hard-coded temperature thresholds drive a tri-colour LED indicator system and an audible buzzer for critical alerts.

  • Studied the NTC thermistor's temperature–resistance curve
  • Implemented Steinhart–Hart calibration for accurate readings
  • Green / Yellow / Red LEDs for normal, warm & critical ranges
  • Buzzer activates when temperature crosses the critical threshold
  • Full control logic in C++, developed & uploaded via Arduino IDE
