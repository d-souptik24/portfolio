## 🌟 About the Portfolio

This repository contains the source code for my personal portfolio website. It serves as a digital resume and a central hub for my software engineering projects, illustrating my journey from a Physics background into the world of Information Technology. The site is built from scratch without heavy frameworks, emphasizing performance, clean code, and a premium user experience.

## 🔗 Live Portfolio

✨ **https://d-souptik24.github.io/portfolio/** ✨

## 🛠️ Tech Stack

- **Structure:** HTML5 (Semantic & SEO Optimized)
- **Styling:** CSS3 (Vanilla, Custom Properties, Responsive Grid/Flexbox)
- **Interactivity:** JavaScript (Vanilla ES6+)
- **Hosting:** GitHub Pages

## 🎨 Design Philosophy

The portfolio features a fully custom **Dual-Theme Design System**, allowing users to seamlessly switch aesthetics based on their preference:

- ☀️ **Light Mode:** A warm, editorial aesthetic utilizing ivory backgrounds, clay orange accents, and the elegant *Source Serif 4* font.
- 🌙 **Dark Mode:** A sleek, modern tech vibe featuring a "void black" background, electric iris (violet) glows, and clean sans-serif typography (*Red Hat Text / Inter*).

*Key UI/UX Elements:* Smooth scrolling, scroll-reveal animations, custom 3D card tilts, edge-glow pointer tracking, and a dynamic HTML5 canvas particle background in dark mode.

## 🚀 Featured Projects

The portfolio highlights some of my most significant builds:

### 1. CivicPulse — Hyperlocal Civic Issue Tracker
*An AI-powered citizen reporting platform.*
- **Tech:** React, Node.js, Express, Firestore, Cloud Run, Docker, Gemini AI
- **Overview:** Uses autonomous AI agents to categorize, deduplicate, and verify civic issues reported by citizens in real-time.

### 2. ECG Image Digitization System
*Medical data recovery pipeline.*
- **Tech:** Flutter, Flask, Python, PyTorch, ESP-32 CAM
- **Overview:** Converts legacy paper ECG printouts into structured 12-lead digital time-series data using a 3-stage deep learning ensemble model.

### 3. Wanderlust — Airbnb Clone 🚧 *(In Progress)*
*Full-stack property listing platform.*
- **Tech:** Node.js, Express.js, MongoDB, EJS
- **Overview:** A complete MVC-based rental marketplace featuring property lifecycle management, authentication, and image uploads.

### 4. Arduino Temperature Monitor Prototype
*Calibrated embedded analog sensor system.*
- **Tech:** C++, Arduino Uno, NTC Thermistor
- **Overview:** Uses the Steinhart–Hart equation for precision temperature calculation, featuring threshold-triggered LED indicators and alarms.
